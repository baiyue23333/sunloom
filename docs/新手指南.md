# 新手指南 · 10 分钟上手

> 面向第一次用 SUNLOOM 的人。装好之后照着 §2 走一遍，就能出第一张图和第一张配方。

## 0. 你需要什么

| 必需 | 说明 |
| --- | --- |
| ComfyUI | 能跑就行（0.3.60+，0.42.x 验证过），本站不打包模型 |
| 模型三件套 | UNet / checkpoint、文本编码器、VAE；先在 ComfyUI 里跑通一张 |
| Python 3.10+ | 只用来跑本站后端 |

单文件 checkpoint 用户：把 `station/workflows/t2i.json` 里的加载节点换成 `CheckpointLoaderSimple` 即可。

## 1. 装上并跑起来

**方式 A（推荐）：一键脚本**

```
powershell -ExecutionPolicy Bypass -File install/install.ps1
powershell -ExecutionPolicy Bypass -File install/bind_pipeline.ps1
```

第一个脚本装依赖、问你的 ComfyUI 目录、让你选模型、写 `station/data/config.json`；
第二个做连通性校验（ComfyUI 在线、模型在、节点齐）。

**方式 B：手动**

```
python -m pip install -r requirements.txt
copy config.example.json station\data\config.json   # 然后按注释改路径
```

**启动**：双击根目录 `start.bat`（换端口：`start.bat 8791`），浏览器会打开 `http://127.0.0.1:8790/`。

> 启动后先看**右上角**：`ComfyUI 0.42.0` 这种绿色表示已连上；`ComfyUI 未启动` 就先开 ComfyUI。

## 2. 第一张图（5 步）

1. 打开「拼装」页，点左侧积木库的 **@SUBJ**（主体）、**@CAM_BUST**（胸像）、**@OUT_CASUAL**（衣服）、**@LIGHT_WIN**（窗光）；
2. 右侧「参数」：尺寸 1024×1536、步数 28、CFG 5.5，种子留空；
3. 点「出图」，等进度条走完；
4. 结果面板：满意就点 **A**（登记），不满意点「重抽」；
5. 出过的图都在「画廊」，标了等级的会进登记表。

> 第一张不用纠结提示词——先确认「积木 → 展开 → 提交 ComfyUI」这条链通了。

## 3. 看懂画布

| 概念 | 一句话 |
| --- | --- |
| 正向 / 负向 | 两条泳道，负向写「不要什么」 |
| 权重 | 每块右侧数字，0.8–1.5 常用；写成 `(内容:1.3)` |
| 顺序 | 会改变效果：主体 → 机位 → 场景 → 光 → 身份/服装 → 表情 |
| 分类 | 左侧按「身份/体型/机位/打光/场景/道具/构图…」分组，可折叠 |
| 配套 | **加正向时自动带配套**：加 `@OUT_XXX` 自动补 `@NEG_XXX`；加 `@DRAPE_OFF` 补 `@NEG_DRAPE_ON`；加武器补 `@WEAPON_GRIP` |
| 悬停 | 鼠标停在积木上可看备注（用法与坑） |
| 双击 | 任意积木双击看详情：展开文本、备注、实测状态 |

负向底线：`@NEG_BASE`（分屏/双人/水印）+ `@NEG_HANDS`（手指）。别空着负向直接出图。

## 4. 快速模板：别从零开始

「拼装」页中间的**快速模板**一点就摆好整组积木，再改两三个词就行。

- 想存自己的：摆好积木 → 卡片右上角 **＋ 创造模板** → 起名保存；
- 模板存的是「积木 + 参数」，不含图片；
- 模板太多时用搜索框过滤。

## 5. 改图：局部重绘

「复现」页 → 载入底图 → 用**画笔**涂要重画的地方（或切「框选」拖矩形）：

- 笔刷 4–90 px、羽化 0–40；涂完会显示覆盖率；
- 画错了点**撤销**或 `Ctrl+Z`；
- 想复用：**存蒙版** → 下次「调蒙版」一键套用；
- 重绘幅度 0.45–0.6 修细节，0.7–0.85 换内容。

## 6. 每张图都能查回配方

任何结果图点「参数」都会显示：尺寸/步数/CFG/种子/LoRA/展开后的正负向，以及**用了哪些积木**。

- 新图会记住真实积木（含权重）；
- 老图没有积木记录时，会从 PNG 里的 ComfyUI 元数据反推，并标注「按提示词反推 · 权重不精确」；
- 「配方」页可以按时间翻全部记录。

## 7. 常用组合（直接抄）

| 想要 | 加这些 |
| --- | --- |
| 胸像肖像 | `@SUBJ` `@CAM_BUST` `@ID` `@OUT_DRESS` `@LIGHT_WIN` |
| 全身立绘 | `@SUBJ` `@CAM_FULL` `@OUT_CASUAL` `@POSE_STAND` `@LIGHT_GOLDEN` |
| 夜景氛围 | 上面任一组 + `@SET_STREET` `@TIME_NIGHT` `@LIGHT_NEON` |
| 居中棚拍 | `@CAM_BUST` `@COMP_CENTER` `@COMP_MINIMAL` `@LIGHT_WIN` |
| 三分留白 | `@CAM_BUST` `@COMP_THIRDS` `@COMP_NEGATIVE` `@COMP_LOOKROOM` |

## 8. 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 右上角「ComfyUI 未启动」 | ComfyUI 没开，或端口不是 8188；引擎页可看详细状态 |
| 出图报「缺节点」 | 你的 ComfyUI 少了某个节点；引擎页会列出名字 |
| 报模型找不到 | `config.json` 里的模型名和 ComfyUI 里不一致 |
| 方图出双人分屏 | 换 1024×1536 竖图，或负向加 `@NEG_BASE` |
| 显存爆 / 很慢 | 降尺寸到 768、步数降到 20；或开 ComfyUI 的 `--lowvram` |
| 端口被占用 | `start.bat 8791` 换端口 |
| 改完没变化 | 刷新页面；静态资源带版本号，普通刷新即可 |

## 9. 扩展

- **加自己的积木**：词库页新建（名字 `@YOURS`），内容写英文提示词，保存时连备注一起写；
- **加自己的服装**：服装页「+ 新建」，填正向整段 + 配套负向 + 注释；保存后会自动有 `@OUT_<KEY>` / `@NEG_<KEY>`；
- **导入导出**：角色卡、模板、配方都支持 JSON 导入导出；
- **可选模块**：打标（`tools/tag_wd14.py`）、训练（`tools/train_lora.ps1`），不开也能正常出图。

## 10. 数据在哪

```
station/data/   config.json（ComfyUI 路径与模型）
                prompt_lib.json（积木与备注）
                character.json（服装等角色资产）
                templates.json（快速模板）
                recipes.json（每张图的配方）
                registry.jsonl（A/B/C 登记）
station/output/ 出图结果
```

备份只要拷 `station/data/`。误删了内容可以看同目录的 `*.bak`。
