# 系统介绍

## 这是什么

SUNLOOM 是一个「积木式」的出图工作站：把提示词拆成可复用、可排序、带权重的积木，
在网页里拼装成正向/负向提示词，再通过 ComfyUI 的 HTTP API 出图，并自动记录配方。

它不绑定任何角色、画风或模型。人物特征、服装、场景都由积木库描述，
模型和文本编码器由你在安装时绑定。

## 设计原则

1. 提示词是一等公民：所有积木都是可读的文本，不是黑盒；
2. 工作流即数据：ComfyUI 的节点图存成 JSON，由后端替换占位符后提交；
3. 配方可回溯：每张图都记录当时用了哪些积木、权重、参数、LoRA、种子；
4. 自检优先：出图前跑结构检查，缺主体、负向为空、杯子冲突都会被拦下；
5. 不打包 ComfyUI：本仓库只提供前端 + 后端 + 工作流模板，ComfyUI 由你安装。

## 功能一览

| 模块 | 能力 |
| --- | --- |
| 拼装 | 积木库、正负向画布、权重、快速模板、展开预览、结构检查 |
| 出图 | 文生图、图生图（参考图 + 重绘幅度）、LoRA 链、种子/步数/CFG/尺寸 |
| 画廊 | 缩略图、文件名搜索、点击看大图、删除进回收站 |
| 词库 | 分类、A→Z、积木增删改、备注、导入导出 |
| 服装 | 套装库：默认、复制、材质/型态、导入导出，替换 @OUTFIT |
| 配方 | 自动记录每张图的完整参数与积木，随时回查 |
| 引擎 | ComfyUI 状态/版本/设备、工作流节点检查、启动与释放显存、模型绑定 |
| 维护 | 体积统计、回收站恢复/清空、文档列表 |
| 打标 | 可选模块：WD14 打标，预览或写入 .txt |
| 训练 | 可选模块：kohya LoRA 训练，日志与进度 |

## 架构

    浏览器（static/index.html + app.js）
        |
        | HTTP JSON
        v
    FastAPI（station/server.py）
        |-- prompts.py   词库读取 / 宏展开
        |-- ir.py        结构检查
        |-- graph.py     工作流 JSON + 占位符替换 + LoRA 链
        |-- comfy.py     ComfyUI 客户端（提交 / 轮询 / 取图 / 释放）
        v
    ComfyUI（你自己的安装，HTTP 8188）
        v
    output/*.png  +  data/recipes.json

## 环境要求

- Windows 10/11（脚本为 PowerShell；其他系统可手动执行等价命令）
- Python 3.10+
- ComfyUI（推荐 0.3.60 及以上，本项目在 0.42.x 上验证）
- 一个 UNet/checkpoint、一个文本编码器、一个 VAE（由安装脚本写入 config.json）
- 显存：1024x1536、28 步在 8GB 卡上可跑（约 70-90 秒/张，取决于模型）

## 明确不做的事

- 不下载、不打包模型权重；
- 不内置任何角色 LoRA 或私有资产；
- 不包含模型训练；也不含任何云端 GPU 相关功能；
- 不替代 ComfyUI 的节点能力，只做提示词与流程的编排。
