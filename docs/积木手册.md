## 怎么组合

一个稳的组合顺序（也是快速模板的顺序）：

    @SUBJ -> @CAM_* -> @FACE -> @OUT_* / @OUTFIT -> @BODY -> @POSE_*
          -> @PROP_* -> @SET_* -> @LIGHT_* -> @ATMO_* / @TIME_*

负向：@NEG_HANDS + @NEG_BASE + @NEG_EXPO，按需要加 @NEG_CUP / @NEG_OBJECTS。

## 写新积木的建议

1. 一条只做一件事：不要把服装和场景写在一起；
2. 用 booru 认识的说法：small breasts、upper body close-up、backlight；
3. 关键概念用括号加权重，其余保持 1.0；
4. 负向只写「不要什么」，不要写「要什么」；
5. 加完在工作站里试 2-3 张，确认它在不同种子下都稳。
