# 工作站说明

## 启动

    cd station
    python -m uvicorn server:app --host 127.0.0.1 --port 8770

Windows 也可以：

- 双击根目录的 start.bat（自动找 Python、检查依赖、开浏览器；端口可传参 start.bat 8771）
- 或运行 station/start.ps1

## 页面

### 拼装

- 左侧积木库：按分类分组，悬停看备注，点一下加进画布（@NEG_* 自动进负向）；
- 中间正向 / 负向画布：每块可改权重、可删除、可清空；
- 快速模板：点一下整组替换；
- 结构检查：出图前自动跑，也可手动点；
- 展开预览：看宏展开后的最终提示词与字符数；
- 右侧参数：模式（文生图 / 图生图）、尺寸、步数、CFG、种子、前缀、LoRA、参考图、重绘幅度。

### 画廊

- 文件名搜索，点击看大图；
- 大图里可以「查看参数」（跳到配方）或「删除」（进回收站）。

### 词库

- 列出全部积木与备注；
- 点一条进入右侧编辑；保存后立即生效；
- 删除是物理删除，会同时删掉备注。

### 服装

- 套装库：每个 key 是一段可复用的服装描述；
- 默认套装会替换 @OUTFIT 宏；
- 至少保留一套。

### 配方

- 每张图出图时自动记录；
- 点条目看：模式、种子、尺寸、步数、CFG、重绘幅度、正负向全文、积木清单。

### 引擎

- ComfyUI 状态、版本、设备、显存；
- 工作流列表与缺失节点；
- 「释放显存」「启动」「打开 ComfyUI」；
- 模型绑定表单（写入 data/config.json）；
- 「运行环境自检」：显示 /api/pipeline/check 的结果。

### 维护

- 输出目录 / 回收站体积、磁盘剩余；
- 清空回收站；
- 文档列表（点击在弹窗里读）。

## 配置

station/data/config.json 由安装脚本生成，也可以手改：

    {
      "comfy_url": "http://127.0.0.1:8188",
      "comfy_dir": "A:/ComfyUI",
      "model": {
        "unet_name": "your-model.safetensors",
        "clip_name": "your-text-encoder.safetensors",
        "vae_name": "your-vae.safetensors",
        "clip_type": "stable_diffusion"
      },
      "defaults": { "size": "1024x1536", "steps": 28, "cfg": 5.5,
                    "sampler": "euler", "scheduler": "simple", "loras": [] },
      "output_dir": "output"
    }

comfy_dir 有两个用途：图生图时把参考图复制进 ComfyUI/input；「启动」按钮拉 ComfyUI。

## API 速查

| --- | --- | --- |
| GET | /api/bootstrap | 词库、模板、套装、默认参数、ComfyUI 状态 |
| POST | /api/expand | 展开正负向宏，处理杯子冲突 |
| POST | /api/validate | 结构检查 |
| POST | /api/run | 出图（t2i / i2i） |
| GET | /api/job/{id} | 任务进度与结果 |
| GET | /api/gallery?q= | 画廊列表 |
| POST | /api/delete-image | 删除进回收站（仅限 output 目录） |
| GET | /api/recipes | 配方列表 |
| GET | /api/recipe?path= | 单张配方 |
| POST | /api/token/save | 保存积木 |
| POST | /api/token/delete | 删除积木 |
| POST | /api/garment/save | 保存套装 |
| GET | /api/engine | ComfyUI 与工作流状态 |
| POST | /api/comfy/free | 释放显存 |
| POST | /api/comfy/start | 启动 ComfyUI |
| POST | /api/config | 保存模型绑定 |
| GET | /api/docs / /api/doc?name= | 文档 |
| GET | /api/maintenance / POST /api/maintenance/cleanup | 体积与清理 |
| GET | /api/pipeline/check | 环境自检 |

## 故障排查

| 现象 | 检查 |
| --- | --- |
| ComfyUI 离线 | 先启动 ComfyUI；引擎页看地址是否 8188 |
| 出图报 missing nodes | 引擎页看工作流缺失节点，升级 ComfyUI 或装节点 |
| 出图报 model not found | config.json 的模型名要写 ComfyUI 目录下的文件名，不带路径 |
| 图生图报 comfy_dir | 安装脚本没写 comfy_dir，重跑 bind_pipeline.ps1 |
| 出图画完了但画廊没有 | 输出目录不是 output？检查 output_dir |
| 端口占用 | start.ps1 -Port 8771 |
