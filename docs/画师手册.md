# 画师手册

这份文档只讲「怎么用积木把图做出来」，不涉及代码。

## 1. 一次出图的最小流程

1. 打开工作站，进「拼装」页；
2. 左侧点 @SUBJ（主体）和 @CAM_BUST（机位）；
3. 点一个服装（@OUT_CASUAL 或「服装」页选的 @OUTFIT）；
4. 点一个光（@LIGHT_WIN 最稳）；
5. 右侧选尺寸、步数、CFG，点「出图」。

结构检查会拦下三种常见错误：没有主体、负向为空、负向里禁了正向要拿的东西。

## 2. 积木的五个维度

| 维度 | 回答的问题 | 常用 |
| --- | --- | --- |
| 主体/体型/脸 | 画谁 | @SUBJ @BODY @FACE |
| 机位 | 从哪看 | @CAM_BUST @CAM_FULL @CAM_MEDIUM |
| 姿势/手 | 在做什么 | @POSE_* @HAND_* |
| 光/氛围 | 什么时间、什么空气 | @LIGHT_WIN @LIGHT_NIGHT @ATMO_RAIN |
| 服装/场景/道具 | 穿什么、在哪、拿什么 | @OUT_* @SET_* @PROP_* |

光的影响最大，其次机位，再其次姿势。构图不稳时先换光和机位，不要先改脸。

## 3. 权重怎么用

- 1.0：默认，积木自己的权重已经够；
- 1.2-1.4：这一块必须成立（比如「看着镜头」）；
- 0.6-0.9：只要一点点（比如轻微景深）；
- 超过 1.5 容易让画面变硬、出现塑料感。

括号写法 (text:1.3) 是扩散模型的标准加权语法，系统会自动包好，不必手写。

## 4. 相机与光的速查

| 想要 | 用 |
| --- | --- |
| 头像/半身 | @CAM_BUST |
| 七分身 | @CAM_MEDIUM |
| 全身带环境 | @CAM_FULL + @COMP_WIDE |
| 柔和人像 | @LIGHT_WIN 或 @LIGHT_SOFT |
| 情绪/电影感 | @LIGHT_NIGHT + @ATMO_BOKEH |
| 剪影/逆光 | @LIGHT_BACK + @LIGHT_RIM |

## 5. 参数建议

| 参数 | 建议 | 说明 |
| --- | --- | --- |
| 尺寸 | 1024x1536 / 832x1216 | 竖图主体占比更好；横构图用 1536x1024 |
| 步数 | 24-32 | 低于 20 细节不足，高于 36 收益很小 |
| CFG | 4.5-6.5 | 太高会硬，太低会散；默认 5.5 |
| 种子 | 先随机，满意后固定 | 固定种子只改变量，便于对比 |
| 重绘幅度（i2i） | 0.45-0.6 改细节，0.7-0.85 换内容 | 超过 0.85 基本等于重画 |

## 6. 迭代循环（重要）

1. 固定种子；
2. 一次只改一个积木或一个参数；
3. 存下满意那张的「配方」；
4. 连续两次改不动，就换机位或光，不要在同一个构图上死磕。

## 7. 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 手崩 | 手部描述太弱 | 加 @HAND_FOLD 或 @HAND_CHIN，让手有事做 |
| 画面发灰 | 光太弱 / 负向过重 | 换 @LIGHT_WIN，去掉多余的负向 |
| 主体太小 | 机位太远 | 换 @CAM_BUST / @CAM_MEDIUM |
| 衣服被画没 | 服装块权重低 | 服装提到 1.3，或在「服装」页改成更具体的描述 |
| 构图重复 | 模板太像 | 换 @CAM_* 与 @COMP_*，或改 seed |
| 出现多余物件 | 场景描述太满 | 减场景块，负向加 @NEG_OBJECTS |

## 8. 风格统一

- 同系列图固定：模型、LoRA、采样器、步数、CFG、尺寸；
- 只让积木、种子变化；
- 参考图的风格要写进正向前几条，否则会被场景词盖掉。

## 9. 什么时候该换模型

- 手和脸反复崩：换更强的底模，而不是继续加负向；
- 风格不匹配：换画风 LoRA，而不是堆 style 词；
- 构图永远一样：换采样器或调度器，或者把 CFG 降 0.5。
